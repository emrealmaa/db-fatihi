# Ekran görüntüleri

Geliştirme veritabanında (`npm run db:kur` sonrası temiz seed) bir simülasyon günü çalıştırılarak alındı (`yonetici` hesabı, 10x hız).
Sunum şablonuna doğrudan eklenebilir (1568×726).

| Dosya | Gösterdiği |
|---|---|
| `01-masalar.jpg` | Masa panosu: 25 masa, 3 kat; masa 3 oyun sırasında |
| `02-masalar-vip-kat.jpg` | Kat 3 · VIP Kulüp masaları altın VIP rozetiyle |
| `03-oyunlar-vip.jpg` | Oyunlar → VIP süzgeci: 10 ağır strateji oyunu, kilit rozeti, "Sadece VIP üyeler oynayabilir" |
| `04-vip-oyun-reddi.jpg` | **Standart müşteriye VIP oyun verilmeye çalışılınca veritabanı reddediyor** (tetikleyici `VIP_OYUN_YETKISIZ`) |
| `05-gun-sonu-fisi.jpg` | Simülasyon günü sonu fişi (`fn_donem_ozeti`) |
| `06-rapor-vip-oyunlar.jpg` | Raporlar → VIP oyunlar (`v_vip_oyun_kullanimi`) |
| `07-rapor-kat-geliri.jpg` | Raporlar → Kat geliri (`v_kat_gelir`): kat 2 yemek geliri, kat 3 VIP geliri ayrı |
| `08-simulasyon-kat1.jpg` | Simülasyon, Kat 1 ve çevresindeki şehir (akşam) |
| `09-simulasyon-kat2-bistro.jpg` | Kat 2 · Strateji Salonu & Bistro: yemek asansörü, servis tezgâhı, sarkıt lambalar |
| `10-simulasyon-kat3-vip.jpg` | Kat 3 · VIP Kulüp: yıldız rozetli üyeler, şömine, VIP vitrin, kadife bariyer |
